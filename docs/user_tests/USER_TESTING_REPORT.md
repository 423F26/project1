# User Testing Feedback

During the week of November 9th, we demoed the current iteration of our software to two users.

## User Testing Questionnaire

Here is a copy of the questionnaire that was sent to both users:

### Instructions

1. Navigate to [https://esof423.csit.help/](https://esof423.csit.help/?utm_source=chatgpt.com) in a web browser.
2. Use either the "Find Company Filings" or "Recent Filings" functionality to find a company or specific filing.
3. Run a new analysis or view an existing analysis (there are existing analyses for PEPSICO INC).

### Questions

1\. If you experienced any notable bugs or glitches during the steps outlined above:

- 1a. Was it with the "Find Company Filings" / Search functionality? Explain your experience.
- 1b. Was it with the "Recent Filings" functionality? Explain your experience.
- 1c. Was it with the page of an individual company (like PEPSICO INC)? Explain your experience.
- 1d. Was it with the "Open Original" document in new tab functionality? Explain your experience.
- 1e. Was it with the "Sentiment" functionality? Explain your experience.
- 1f. Was it with the "Run Report" functionality? Explain your experience.
- 1g. Were there any discrepancies between functionality in English/German?
- 1h. Were there any unexpected changes in functionality between US/German filing markets?
- 1i. Were there any general performance issues, visual impediments, or unclear areas of the application?

2\. How would you describe our website to another person in your field?

3\. In a finished state where financial analysis jobs could be run much faster (e.g., on a dedicated AI workstation), could you see this website as a useful tool on your computer while working in finance-related careers?

4\. What were some things you liked about the website?

5\. Was there anything you disliked about the website?

6\. Do you want to provide any additional feedback or suggestions for the authors?

## User Testing Results

### User 1: "W"

User 1, "W", said that they ran into no issues in the pipeline I detailed, and they were able to generate a report about Apple.

They described our application as:

> "An efficient way to collect data about companies that could be influential for picking stocks. I think it could be huge for people who pick their own stocks because they are able to pore through more real data than before. It reminds me of a Bloomberg terminal that isn't insanely expensive but is missing some functions of a Bloomberg. I like how easy the website is to navigate and how straightforward it is."

### User 2: "J"

User 2, "J", stated they encountered usability issues immediately after opening the website and said it was not immediately apparent to new users what the website did or how to use it.

More helpful tooltips, included in the search box, or built-in documentation could help relieve this.

After minimal intervention by me, they were able to scroll through "Recent Filings," filter results, and eventually search for companies.

They expressed that it was unclear what happens after the "Run Report" button was pressed and said that, due to our current long wait times, we should either add a disclaimer or some sort of progress indicator to our analysis feature.

## Conclusion

Overall, user testing was a success despite our application's state, and with the pointers given to us by both users, we will be able to revise our set of features during the final sprint.
