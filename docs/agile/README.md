# Agile documentation

Keep the ordered [Product Backlog](product-backlog.md) and one short document per sprint under [sprints](sprints/) in the repository. They are the project record for planned and completed work.

## Agent workflow

Before beginning scoped work, inspect the product backlog and its assigned sprint. When work changes state, update the matching rows in both files in the same change that produced the evidence. Use only `Planned`, `In Progress`, `Blocked`, and `Done`; a blocked item must name its next action. Do not add burndown charts, timesheets, hours, or individual performance tracking.
